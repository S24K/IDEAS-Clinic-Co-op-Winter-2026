# IDEAS-Clinic-Co-op-Winter-2026

This repository showcases my Winter 2026 co-op work with the University of Waterloo Engineering Ideas Clinic, where I contributed to mechatronics prototype development, Arduino-based control systems, sensor integration, Python live data visualization, mechanical calibration, testing, troubleshooting, and technical documentation.

The repository also highlights my contributions to the Engineering Ideas Clinic Nuclear Challenge, including the development and refinement of educational materials, documentation, and hands-on learning components designed for student-facing engineering activities.
